# 🛍️ E-Commerce Website

This is a **Next.js e-commerce project** built with modern technologies including:
- Next.js  
- TypeScript  
- Tailwind CSS  
- React Hook Form & Zod  
- Stripe Payment (Visa) and Cash on Delivery  
- Authentication (Login / Register / Forget & Reset Password)  
- Protected Routes & Server Actions  
- Real APIs and Animations  

---

## 🔧 Features
- User authentication and authorization  
- Add to cart and checkout  
- Payment with Stripe or Cash  
- Fully responsive modern design  
- Smooth animations and transitions
